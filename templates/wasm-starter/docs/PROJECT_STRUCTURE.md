# Project structure

```text
src/
  lib.rs                  # wasm_bindgen exports + pure logic
  main.rs                 # native demo over the pure logic
  _feature_template.rs    # copy-paste starter for new exports
tests/
  test_greet.rs           # native integration tests (cargo test)
  web.rs                  # browser tests (wasm-pack test, wasm32 only)
pkg/                      # generated by wasm-pack (gitignored)
www/
  index.html              # Vite demo page
  src/main.js             # imports pkg/ bindings, calls one exported fn
  package.json            # demo deps (vite)
  vite.config.js          # serves pkg/ output
```
